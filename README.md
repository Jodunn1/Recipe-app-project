# 🍽️ Recipe App

Welcome to the **Recipe App** – a simple and user-friendly application that allows users to manage their favorite recipes with ease. Whether you're a home chef, a food enthusiast, or just someone looking to organize your cooking ideas, this app is made for you!
## 🚀 Features

With the Recipe App, you can:

- **Create Recipes** – Add your own custom recipes, complete with ingredients and instructions.
  ![React-app4](https://github.com/user-attachments/assets/be41f8d6-d224-453e-9c0c-f2c074a82259)

- **View Recipes** – Browse all the recipes you've added in a clean, readable format.
  ![React-app2](https://github.com/user-attachments/assets/a09f520f-2dc5-4966-a012-0ac4d5c28b38)

- **Edit Recipes** – Need to update an ingredient or tweak your cooking steps? Easily make changes to existing recipes.
  ![React-app3](https://github.com/user-attachments/assets/5a8f6c37-763b-4b92-86d0-230da27c0069)

- **Delete Recipes** – Clean up your collection by removing recipes you no longer need.
  ![React-app5](https://github.com/user-attachments/assets/d355bf53-6f56-49ea-b2ec-cffa563413cb)


This app provides a straightforward interface to help you manage your recipe collection all in one place.

## 🛠️ Tech Stack

This project is built using:

- HTML/CSS
- JavaScript
- React
- Python
- Flask
- SQL
- RESTful API
